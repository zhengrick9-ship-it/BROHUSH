先看口径：本文参考了Hermes的“13步主干 + 并行材料设备 + 5条横切线”结构，并结合YOLO前期的需求线、制造线和利润池研究重写。Hermes原文中的2026年7月市值、PE、资金流和“买入/回避”判断没有直接继承，因为它们会随时间变化；本文只保留产业结构和公司角色，个股进入交易研究必须另做点时核验。

一、六条主线与产业链顺序

AI产业的物理制造顺序是从材料和设备开始，经过芯片、存储、互联、供电、服务器和数据中心，最后由模型与应用把基础设施转化为客户结果。六条主线不是六条互相独立的流水线，而是并行输入、在数据中心和应用端汇合。

原材料 / 设备 ↓ 芯片设计与制造：EDA、GPU/CPU/ASIC、晶圆、先进封装 ↓ 存储与互联：HBM/SSD、光芯片/光模块/交换机 ↓ 供电线：功率器件、PSU/UPS/PDU、液冷与CDU ↓ 服务器 / 整机柜 / 数据中心 / 算力服务 ↓ 算力平台：CUDA、驱动、编译器、运行时、调度和推理框架 ↓ 应用线：数据、模型、Agent、行业软件和终端应用

研究时同时使用两种方向：

需求线：从客户往下追

客户想得到什么结果？需要什么模型和数据？需要多大算力、带宽、容量、时延和功率？最终会采购哪些设备与服务？

制造线：从底层往上造

材料和设备怎样形成芯片？芯片怎样封装成加速器？加速器怎样组成服务器和集群？集群怎样变成可交付算力？

投资研究的交汇点

只有当需求形成真实订单、技术形成客户认证、产品形成收入和利润，产业链坐标才有可能变成投资价值。

二、六条主线总览

系统线它回答的问题向下拆解的关键模块
算力线模型如何完成计算？EDA/IP → GPU/CPU/ASIC → 晶圆 → 先进封装 → 加速卡 → 服务器
存储线数据如何被高速读取、缓存和保存？HBM、DDR5/MRDIMM、CXL、NAND、SSD、分布式存储
互联线芯片、服务器和集群如何高带宽通信？光芯片、光模块、CPO、交换芯片、网卡、光纤、铜互联
供电线高功率设备如何安全上电并持续运行？功率器件、变配电、PSU、UPS、PDU，以及与供电协同的液冷、CDU、冷源
应用线算力如何变成客户可以使用的业务结果？数据治理、基础模型、后训练、推理、Agent、行业软件和终端应用
承载线如何把以上系统装起来、部署起来、运营起来？材料设备、PCB/CCL/载板、服务器机柜、IDC机房、网络安全、运维

CUDA、驱动、编译器、运行时、调度和推理框架属于算力线的生态平台底座，不单列为“软件线”；模型、Agent、行业软件和AI终端应用属于应用线。EDA是芯片设计与制造工具，归入算力线前端，不是CUDA，也不是应用软件。承载线不是一个单独零件，而是把各条线组合成可制造、可部署、可运营系统的工程支撑层。

三、13步主干：AI产品从底层到应用

步骤它做什么利润特征代表公司/生态
1. 矿物与高纯原料提供硅、石英、锗/镓/铟、特种气体、电子化学品等物理起点。资源或稀缺纯度带来议价；普通资源利润随周期波动。石英股份、三孚股份、驰宏锌锗、云南锗业、巨化股份
2. 晶圆与硅片把高纯硅转成可用于逻辑、存储、功率器件的晶圆。资本密集、折旧高；领先工艺和高端材料的利润高于普通产能。TSMC、Samsung、沪硅产业、立昂微、天岳先进
3. 芯片设计、EDA与IP把需求变成架构、逻辑、电路、版图和可制造的GDS文件。IP/EDA通常轻资产、高毛利；芯片设计受研发投入和产品成败影响。NVIDIA、Synopsys、Cadence、华大九天、概伦电子、芯原股份
4. 晶圆代工按设计文件制造逻辑芯片、存储芯片或专用芯片。先进制程有技术和规模溢价，但资本开支、良率和产能利用率决定利润。TSMC、Samsung、Intel Foundry、中芯国际、华虹公司
5. 先进封装把逻辑芯片、HBM、Chiplet、硅中介层和载板组合成高密度芯片模组。工艺、良率和稀缺产能可带来较高价值；扩产和良率风险也高。TSMC、ASE、Amkor、长电科技、通富微电、华天科技
6. 算力芯片与高带宽存储提供GPU、CPU、ASIC、DPU、NPU、HBM、DRAM、NAND和接口芯片。平台芯片、软件生态和HBM是高利润池；通用存储具有强周期性。NVIDIA、AMD、Broadcom、SK hynix、Micron、海光信息、澜起科技、江波龙
7. PCB、载板与板级互联承载芯片、供电和高速信号，连接计算、内存、电源与网络。高层数、高速材料、ABF载板和高可靠产品利润优于普通板材。Ibiden、Unimicron、深南电路、沪电股份、胜宏科技、生益科技、兴森科技
8. 光互联与光纤完成电信号与光信号转换，让大规模集群远距离、高带宽通信。光芯片、器件和客户认证价值较高；模块组装利润随价格和竞争分化。中际旭创、新易盛、天孚通信、光迅科技、源杰科技、长飞光纤
9. 服务器、整机柜与集群设备把加速卡、内存、存储、网络、电源、散热和系统软件装成可运行节点。收入规模大但OEM装配利润通常较薄；系统适配、交付和服务能改善利润。Dell、HPE、Supermicro、浪潮信息、工业富联、中科曙光、紫光股份
10. 供电与热管理把电稳定送进机柜，把热量带走，保证连续运行和能效。普通工程集成利润薄；核心电源、CDU、冷板、控制和可靠性方案更有价值。Vertiv、Schneider、Eaton、科士达、中恒电气、伊戈尔、英维克、高澜股份
11. 数据中心与算力服务提供机房、电力指标、网络、机柜、运维和GPU/CPU算力服务。重资产、折旧和电费高；长期合同、上架率和利用率决定回报。Equinix、CoreWeave、阿里云、腾讯云、润泽科技、宝信软件
12. 应用线：数据、模型与推理把算力转成数据资产、模型能力、推理吞吐和Agent执行能力。软件毛利潜力高，但训练/推理成本、销售和客户付费决定净利润。OpenAI、Anthropic、Google、DeepSeek、百度、阿里、腾讯；A股映射需逐项核验
13. AI应用与行业交付把模型嵌入办公、金融、医药、制造、自动驾驶、安防和机器人流程。能形成持续订阅、数据闭环和行业壁垒的应用，长期利润质量可能最高。金山办公、恒生电子、海康威视、大华股份、德赛西威、汇川技术、拓普集团

注意：这些步骤不是所有产品的唯一物理顺序。EDA、材料、设备、网络和电力会以并行方式输入多个环节；应用和模型需求也会反过来改变芯片、存储、互联和服务器设计。

四、逐层展开：当前路线、下一代路线与价值来源

STEP 1–2 · 原料 / 晶圆

从高纯材料到可制造晶圆

底层基础
做什么高纯石英、电子级硅、特种气体、光刻胶、湿电子化学品等决定晶圆制造的纯度、缺陷率和良率。
主流路线石英/硅料 → 拉单晶 → 切片、研磨、抛光 → 逻辑或存储晶圆；化学品和特气同步进入光刻、沉积、刻蚀、清洗。
下一代更大尺寸、更低缺陷晶圆、先进节点材料、高纯气体国产替代、SiC/GaN等宽禁带材料。
利润与风险高纯稀缺材料可能有较强议价权，普通硅片和资源环节强周期。风险是产能过剩、价格下降、认证周期和技术替代。
石英股份三孚股份沪硅产业立昂微天岳先进南大光电
STEP 3 · 芯片设计 / EDA / IP

把需求变成可以制造的电路图

轻资产高壁垒
做什么定义芯片架构、接口、计算单元、内存控制和功耗，再用EDA完成仿真、验证、版图和签核。
主流路线GPU/CPU/ASIC/NPU/DPU多路线并存，EDA由设计、仿真、综合、布局布线、验证组成，IP负责复用成熟模块。
下一代Chiplet设计、3D封装协同设计、硬件/软件协同优化、面向AI推理的专用加速器和开放互联；CUDA不属于EDA，而是芯片完成后的GPU平台生态。
利润与风险成熟EDA/IP具有高毛利和复用收入特征。芯片设计则可能因研发失败、客户自研、软件生态不足而快速失去价值。
NVIDIACadenceSynopsys华大九天概伦电子芯原股份
STEP 4–5 · 代工 / 先进封装

把设计文件变成高密度芯片模组

制程与良率
做什么晶圆代工通过光刻、刻蚀、沉积、清洗和CMP形成芯片；先进封装再把逻辑芯片、HBM和Chiplet组合起来。
主流路线先进逻辑制程 + CoWoS-S/R/L + HBM3E + 2.5D集成；封装还包括倒装、TSV、微凸点和高密度载板。
下一代HBM4/HBM4E、更大封装尺寸、Chiplet、SoIC混合键合、背面供电、玻璃基板和光电共封装。
利润与风险先进制程和高端封装因产能、良率和认证具有溢价。风险是重资本、扩产超前、良率爬坡、出口限制和路线切换。
TSMCSamsung中芯国际长电科技通富微电华天科技
STEP 6 · 算力芯片 / HBM / 存储

决定模型能算多快、数据能搬多快

最大分化
做什么GPU、ASIC、CPU、DPU、NPU负责计算；HBM、DRAM、NAND和SSD负责提供高速和大容量数据。
主流路线训练以GPU/加速器 + HBM为主，推理更多使用专用芯片、量化、缓存和异构计算；CUDA、驱动、编译器和加速库负责把GPU硬件变成可编程、可调用的平台。
下一代HBM4、CXL内存池、计算存储、推理缓存、Chiplet和面向特定模型的ASIC。
利润与风险平台芯片、算力生态、HBM和接口芯片可能是高利润池；通用存储强周期。囤货涨价产生的利润不是技术壁垒，必须区分真实产品、主控固件、企业认证和库存收益。
NVIDIAAMDSK hynixMicron海光信息澜起科技兆易创新江波龙
STEP 7 · PCB / CCL / 载板 / MLCC

承载芯片、信号和供电

材料等级决定价值
做什么PCB和载板承载芯片与高速信号，CCL提供介电和导电结构，MLCC承担滤波、去耦和电源稳定。
主流路线高层数高速PCB、低损耗/超低损耗CCL、ABF载板、高频高速铜箔和高可靠MLCC。
下一代更高层数、更低损耗材料、玻璃基板、更密集互联和面向高功率AI机柜的电源滤波升级。
利润与风险高端材料、载板、MLCC和高速PCB利润优于普通板材。风险是传统电子周期、扩产、铜箔/树脂价格和客户集中。
深南电路沪电股份胜宏科技生益科技兴森科技顺络电子
STEP 8 · 光互联 / 光纤

把集群中的电信号变成可传输的光信号

带宽迁移
做什么激光器、调制器、探测器、DSP、光引擎和光模块完成电—光—光纤—光—电转换。
主流路线800G/1.6T可插拔模块、PAM4、EML/DFB激光器、硅光和LPO；铜互联在短距离仍有成本优势。
下一代CPO、薄膜铌酸锂、光电共封装、Optical I/O、200G/400G每通道和更低功耗调制。
利润与风险高端光芯片、器件、客户认证和新技术平台可能拥有较高价值。模块组装受价格竞争影响；风险是资本开支、客户集中、量产良率和路线迁移。
中际旭创新易盛天孚通信源杰科技长光华芯光库科技兆龙互连
STEP 9–10 · 服务器 / 供电线

把零件变成能上电、联网和持续运行的系统

部署瓶颈
做什么服务器把芯片、内存、SSD、网络、电源和散热集成；供电线解决功率转换、稳定供电，并与液冷系统协同解决热管理。
主流路线风冷服务器、UPS/PDU、服务器电源、冷板式液冷、CDU和机房级冷源；GPU集群采用高速网络互联。
下一代整机柜液冷、浸没式液冷、800VDC/高压直流、机柜级电源、冷板/泵阀控制标准化。
利润与风险OEM装配通常利润薄；核心电源、CDU、冷板、控制和可靠性方案更可能产生溢价。风险是项目回款、现场交付、客户认证、路线不统一和价格战。
浪潮信息工业富联中科曙光科士达中恒电气伊戈尔英维克高澜股份
STEP 11 · 数据中心 / 算力服务

把设备变成客户可以按量使用的算力

重资产运营
做什么提供机房、土地、电力指标、网络、机柜、消防安防、运维和GPU/CPU算力服务。
主流路线传统IDC、云厂商自建、GPU云、专属云、私有化部署和边缘数据中心并存。
下一代高功率密度智算中心、液冷机房、绿色电力、算力调度和跨区域资源池。
利润与风险长期合同、稳定电力和高上架率可改善回报。重资产导致折旧、能源、融资和利用率风险高，算力租赁价格也可能下行。

STEP 12–13 · 应用线 / 模型 / 行业应用

把算力最终转化为客户业务结果

应用线
做什么数据治理、模型训练与后训练、推理、Agent和行业应用把基础设施转化为客户可使用的业务能力。
主流路线通用大模型 + RAG/向量库 + 工具调用 + Agent；企业侧采用公有云、私有化和混合部署。
下一代推理成本下降、长上下文、Agent工作流、行业模型、端侧AI、机器人和物理AI。
利润与风险可持续订阅、数据闭环和行业工作流嵌入，长期利润质量可能高于一次性硬件。风险是算力成本、客户付费不足、开源替代、合规和获客成本。
OpenAIAnthropicDeepSeek金山办公恒生电子海康威视德赛西威汇川技术

五、承载线与并行支撑：把各条主线装起来、跑起来

承载线不是“最后剩下的杂项”，而是AI系统能否真正交付的工程承载。它包括硬件制造承载、系统集成承载和数据中心运营承载；材料、设备、PCB、载板、连接器、服务器、机柜、IDC、电力、制冷、安全和运维会并行输入多个环节。

半导体材料

光刻胶、特气、前驱体、CMP抛光液/垫、靶材、封装材料等反复消耗。利润来自纯度、配方、认证和替代成本；风险是价格、客户集中和替代。

代表：雅克科技、彤程新材、安集科技、鼎龙股份、江丰电子、华特气体。

半导体设备与零部件

光刻、刻蚀、沉积、清洗、检测、封装和测试设备决定良率与产能。设备本体有较高技术壁垒，但收入受晶圆厂资本开支影响。

代表：北方华创、中微公司、拓荆科技、盛美上海、华海清科、长川科技。

通信网络、数据和安全

交换、网卡、光互联、调度、数据治理、权限、审计和安全贯穿整个系统。软件安全可能高毛利，但商业化和客户预算决定兑现。

代表：盛科通信、紫光股份、中兴通讯、深信服、奇安信、安恒信息。

六、利润池怎么分：收入大不等于利润大

一台AI服务器的采购价不能直接拆成“某个厂家的利润”。BOM只说明物料构成，实际利润还要扣除上游采购、折旧、研发、认证、库存、物流、售后、融资和回款成本，而且供应链上的利润存在纵向嵌套。

利润层级典型环节为什么可能赚钱不能忽略的反面
高利润潜力平台芯片、EDA/IP、部分软件知识产权、生态、迁移成本、复用和定价权。客户自研、开源替代、技术路线切换、研发失败。
中高利润但强周期HBM、先进封装、光芯片、核心光器件、高端设备稀缺产能、良率、认证、技术壁垒和高价值量。扩产、价格下降、客户集中、资本开支回撤。
中等利润高端材料、PCB/载板、MLCC、液冷核心部件、UPS/电源可靠性、认证、配方、单机价值量和切换成本。原材料、项目制、交付、行业周期和产品降价。
低到中等利润普通服务器OEM、机柜装配、工程集成规模、交付和服务能够带来收入弹性。客户议价、库存、回款和价格战，收入增长可能不转化为利润。
长期高潜力但不确定AI应用、行业软件、Agent和物理AI订阅、数据闭环、工作流嵌入和行业壁垒。算力成本、客户付费、获客成本、合规和商业化速度。
利润核算的三个禁区：不能把上游毛利和下游毛利简单相加；不能把公司整体毛利率当成AI产品毛利率；不能把BOM价值量当作供应商已经确认的收入。真正的公司研究要回到分部收入、产品价格、客户认证、存货、应收、合同负债和经营现金流。

七、技术路线的迁移：为什么价值会从一个环节扩散到另一个环节

01
计算瓶颈 → 内存带宽

模型越来越大后，单纯增加算力不能解决数据搬运问题，HBM、缓存、CXL和更高效的内存层级获得价值。

02
单机 → 集群

GPU从单卡扩展到整机柜和多机柜，交换芯片、网卡、光互联、铜互联、连接器和网络软件的价值上升。

03
风冷 → 液冷与高压直流

功率密度提高后，传统风冷和低压供电接近边界，冷板/CDU、泵阀、机柜电源、800VDC和能效控制成为新约束。

04
可插拔光模块 → 光电共封装

800G/1.6T先形成批量收入，CPO、硅光、薄膜铌酸锂和Optical I/O是后续可能迁移，但必须经历样品、客户认证和量产。

05
预训练 → 推理与Agent

随着模型训练基础设施逐渐成熟，调用量、推理成本、缓存、工具调用和行业工作流可能成为新的需求源。

八、代表公司怎样使用：产业坐标不是推荐名单

代表公司只是帮助读者定位产业环节。一个公司要进入正式投资研究，至少要通过下面四道门：

第一道：真实位置

公司到底卖什么产品？是核心芯片、关键材料、设备、系统部件，还是仅仅有概念映射？

第二道：客户证据

是否有公告、客户认证、量产、订单、收入占比或可验证的产品出货？不能用“可能供应”代替事实。

第三道：财务兑现

收入、毛利、净利、现金流、库存、应收和合同负债是否支持逻辑？囤货收益与技术能力要拆分。

第四道：估值与风险

当前股价是否已经透支？下一代路线是否还停留在样品？资本开支、供给释放和技术替代是否可承受？

九、结论：AI全产业链的六条主线

AI产业链不是“硅料—芯片—服务器—应用”的单线故事，而是六条主线的交汇：算力线、存储线、互联线、供电线和承载线共同形成可交付的基础设施，应用线把基础设施转化为模型能力、Agent工作流和行业结果。

从利润与技术壁垒看，平台芯片/EDA/IP、HBM与先进封装、高速光互联、核心供电液冷和高端材料设备，是更容易形成结构性价值的模块；从收入弹性看，服务器、网络、存储和数据中心可能更快放量，但利润率、库存和资本开支风险更高；从长期变现看，能够嵌入客户流程的模型、Agent和行业应用，才是产业最终的利润出口。

因此，后续研究不应先问“哪只股票属于AI”，而应按“产业 → 模块 → 专题 → 个股”推进：先判断需求是否真实，再判断价值点是否有壁垒，最后用公告、财务和交易数据确认公司是否真正受益。
